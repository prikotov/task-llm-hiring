Замечания
1. T09-L8: `use` внутри тела функции — это parse error (проверено на 8.5), а не «импорт, действующий на весь файл»; обоснование описывает несуществующий код, и возможна путаница с `use ($x)` у замыканий (тот действительно локален) — лучше переписать утверждение, явно назвав «импорт use».
2. T10-L6 — единственное утверждение половины с реальным версионным сдвигом: в PHP 5 by-value foreach при refcount=1 шёл по самому массиву (классический готча с бесконечным циклом); стоит добавить «в PHP 7+» или принять это в методике как допустимое.
3. T09-L2: пример `use function strlen;` в глобальном пространстве даёт warning «The use statement with non-compound name has no effect» (проверено); для чистоты лучше функцию из namespace.
4. T12-L3/T12-L8 неявно предполагают конфигурацию по умолчанию: при session.auto_start=1 ответ на T12-L8 мог бы читаться иначе; стоит добавить «при настройках по умолчанию».
5. T10-L3: суперглобальные ($_GET, $_SERVER…) — тоже глобальные переменные, доступные в функциях без global; уточнить «пользовательские переменные глобальной области».
