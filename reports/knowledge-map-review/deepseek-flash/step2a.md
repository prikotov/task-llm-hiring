**Замечания**

1. Единственная фактическая ошибка половины — T01-L7: в PHP 8 `.` имеет приоритет **ниже** `+`/`-`, поэтому выражение реально даёт `'сумма: 5'`, а TypeError не возникает. Утверждение склеивает ложную посылку (PHP 7) с верным для PHP 8 выводом — его надо переписать, иначе грамотный ответ «да» формально защитим.
2. Версионность почти везде безопасна (T02-L4, T01-L6, T04-L7 называют версию явно). Исключение по строгости — T03-L1 (`str_contains` лишь с 8.0) и T05-L3/T05-L4 (`fn` лишь с 7.4): для 8.x ответ стабилен, но формулировки не защищают от чтения «а в PHP 7?».
3. T05-L8 неточна по сути: ограничение касается только **позиционного** аргумента после распаковки; именованные после `...$args` разрешены (проверено). Стоит добавить это слово, иначе утверждение читается шире, чем правило.
4. T06-L5 требует оговорки: в 8.3+ readonly-свойство разрешено переинициализировать внутри `__clone()`, а инициализация вообще возможна только изнутри класса (8.1). Без этого утверждение «только один раз» уязвимо для формального возражения.
5. Мелкие неточности обоснований (не ответов): T02-L6 — «TypeError в арифметике с нечисловой строкой» верно лишь для чисто нечисловых строк (`'42abc'` даёт warning); T03-L5 — перечень дефолтных символов неполон (не упомянут `\x0B`), хотя сам ответ верен.
