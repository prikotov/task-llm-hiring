# Эксперимент: дополнительные вероятностные метрики decision-моделей

Дата: 2026-10-08. Полигон: ornith-1.5-9b (run-01), кросс-валидация на
ornith-1.5-35b (run-06) и qwen3.8 (run-06). Эталон — изолированные
вердикты GLM-5.3-Flash. Данные: `<модель>/backend/judgments/metrics-clef-<run>.csv`
(и `metrics-clef-flash-<run>.csv` для 9b).

## Метод

К каждому ответу clef задавал 7 дополнительных вопросов (noul/score):
`has_code`, `structured`, `depth`, `names_api`, `precise_numbers`,
`self_doubt`, `contradictions` — script `interview/judge_metrics.py`.
Стоимость: 17–40 с на прогон.

## Корреляции с эталоном (clef, по трём моделям)

| Метрика | corr(балл Flash): 9b/35b/qwen | corr(галлюцинация Flash) | Вывод |
|---|---|---|---|
| contradictions | −0.64 / −0.51 / −0.42 | +0.61 / +0.30 / +0.30 | **самая устойчивая метрика качества** |
| names_api | −0.43 / −0.29 / −0.26 | +0.60 / +0.45 / +0.35 | **устойчивый маркер галлюцинаций** |
| has_code | −0.46 / −0.19 / −0.27 | +0.49 / +0.32 / +0.38 | маркер галлюцинаций |
| precise_numbers | −0.41 / −0.35 / −0.55 | +0.10 / +0.28 / +0.37 | слабый, растущий |
| structured / depth / self_doubt | ≈ 0 | ≈ 0..0.4 неустойчиво | **пустышки — выкинуть** |

Ключевой паттерн (устойчив на всех трёх моделях): **уверенная конкретика
(имена API, код, точные числа) коррелирует с галлюцинациями и отрицательно
с баллом эталона**. Отчасти механически: галлюцинации занижают балл Flash;
но как триажный признак это работает. У clef-flash те же знаки, но
contradictions ловит только большой clef (0.22 против 0.61).

## Комбинация как детектор галлюцинаций

`names_api + has_code + contradictions + 2·clef_hall_p`, порог = медиана:

| Детектор | Точность | Полнота |
|---|---|---|
| clef_hall_p > 0.5 (базовый) | 100% | 40% |
| **комбо (метрики + p)** | **71%** | **87%** (qwen3.8: 12/12) |

Двухступенчатый триаж: p>0.5 → «наверняка ложь» (без проверки);
комбо > медианы → «подозрительно» → досмотр Flash. Вместе покрывают
практически все галлюцинации при малом числе ложных тревог.

## Оговорки

1. Порог «медиана» адаптивный — демонстрация силы сигнала, не готовое
   правило; боевой порог подобрать на размеченных данных.
2. n=117, один домен (PHP-собес) — при новой роли перекалибровать.
3. Отрицательная корреляция конкретики с баллом не универсальный закон,
   а свойство этого набора (модели, выдумывающие конкретику).
4. clef-flash собираем (совпадает по знакам на has_code/names_api),
   но contradictions — только большой clef.
