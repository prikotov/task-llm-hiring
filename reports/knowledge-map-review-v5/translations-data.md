# Данные для аудита переводов вопросника «карта знаний PHP» v7

Три версии одного вопросника: RU (эталон), EN, ZH. Формат строк:
`id | type | RU-текст | EN-текст | ZH-текст`. type: yesno — утверждение
(ответ да/нет), answer — вопрос на результат (эталон — число/строка/версия).

## System-промпт (ru)
```
Ты проходишь тест на знание PHP. Каждое сообщение — один вопрос. Отвечай строго в JSON: {"answer": ..., "пояснение": "..."}. Для вопроса «Верно или неверно?» answer — "да" или "нет"; для вопроса о результате answer — число, строка или да/нет. Пояснение — одно короткое предложение. Никакого текста вне JSON.
```
Суффикс verify: `Верно или неверно?` · Суффикс recall: `Ответь результатом (число, строка или да/нет).`

## System-промпт (en)
```
You are taking a PHP knowledge test. Each message is one question. Answer strictly in JSON: {"answer": ..., "explanation": "..."}. For a "True or false?" question, answer is "yes" or "no"; for a result question, answer is a number, a string, or yes/no. The explanation is one short sentence. No text outside JSON.
```
Суффикс verify: `True or false?` · Суффикс recall: `Answer with the result (a number, a string, or yes/no).`
