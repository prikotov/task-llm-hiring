feat: учёт расходов на LLM-токены — тарификация событий по истории цен

Консольное приложение (Symfony console + Doctrine ORM + PostgreSQL):

- `app:prices:import <file>` — идемпотентная загрузка справочника
  (провайдеры по `code`, модели по `(provider, code)`,
  строки цен по `(provider, model, valid_from)`);
- `app:usage:import <file>` — приём JSONL-событий с дедупликацией по
  `(provider, provider_request_id)` (повторные доставки игнорируются,
  ни одно событие не обновляется);
- `app:billing:rate` — тарификация нерассчитанных событий ценой,
  действовавшей в момент `ts` (valid_from включительно), со схемой
  тарификации провайдера (раздельные ставки / единая) и оф-пиковым
  окном UTC (start включительно, end исключительно, переход через
  полночь); unrated-события не ошибка — повторные попытки при каждом
  запуске (вывод: `RATED=<n> UNRATED=<m>` в stdout, детали — stderr);
- `app:billing:report [--from --to]` — CSV-отчёт по (user, model)
  с TOTAL, точное воспроизведение примера из TASK.md байт-в-байт;
- `app:billing:reprice <file>` (бонус) — ретро-коррекция строки цены и
  пересчёт событий, тарифицированных именно этой строкой
  (`REPRICED_EVENTS=<n>`, `REPRICE_DELTA_USD=<x.xxxxxx>`).

Деньги — только точная десятичная арифметика (bcmath, float не
используется): промежуточные вычисления с масштабом 16, единственное
округление стоимости события — HALF_UP до 6 знаков; суммы отчёта —
сумма уже округлённых стоимостей.

Схема БД — миграция Doctrine (разворачивается на чистой базе,
`make migrate`); unit-тесты домена и парсинга ввода — tests/ (20/20).
