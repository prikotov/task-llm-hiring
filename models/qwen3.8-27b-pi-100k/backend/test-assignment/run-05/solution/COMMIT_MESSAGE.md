# Учёт расходов на LLM-токены: импорт цен и событий, тарификация, отчёт, reprice

Консольное приложение для учёта расходов на LLM-токены:

- `app:prices:import <file>` — идемпотентный импорт провайдеров, моделей и
  строк цен (JSON) из `src/Service/PricesImporter.php` и
  `src/Service/PriceFields.php`;
- `app:usage:import <file>` — импорт событий использования (JSONL) с
  дедупликацией по `(provider, provider_request_id)`;
- `app:billing:rate` — тарификация нерассчитанных событий по цене,
  действовавшей в момент события, с учётом оф-пикового окна, повторная
  попытка для unrated-событий при каждом запуске;
- `app:billing:report [--from=… --to=…]` — CSV-отчёт по (user, model) в
  stdout с TOTAL-строкой;
- `app:billing:reprice <file>` (бонус) — ретро-коррекция строки цены и
  пересчёт тарифицированных ею событий, вывод `REPRICED_EVENTS`/
  `REPRICE_DELTA_USD`.

Дополнительно: доменная модель (Provider / Model / PriceRow / UsageEvent),
расчёт только точной десятичной арифметикой на bcmath (float для денег не
используется), единственное округление стоимости события — HALF_UP до 6
знаков, миграция схемы для чистой базы, unit-тесты расчётной логики
(PHPUnit).
