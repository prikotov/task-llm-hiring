# Billing: учёт расходов на LLM-токены

Консольный сервис тарификации потребления LLM-токенов: импорт истории цен (JSON)
и событий использования (JSONL) в PostgreSQL, расчёт стоимости событий с учётом
исторических цен, схем тарификации и оф-пиковых окон, CSV-отчёт в разрезе
(user, model), идемпотентное повторное прогон и ретро-коррекция цен.

- Деньги — только точная десятичная арифметика (bcmath, без float);
  округление ровно одно — итоговая стоимость события (HALF_UP, 6 знаков).
- Событие тарифицируется строкой цен с наибольшим `valid_from ≤ ts`;
  «висящие» события остаются unrated и добираются повторным запуском.
- Дедупликация событий по естественному ключу `(provider, provider_request_id)`.
- Бонусная команда `app:billing:reprice`: upsert исправленных строк цен и
  пересчёт событий, рассчитанных этими строками, с выводом дельты.
- Схема БД разворачивается миграцией на чистой базе; покрыто тестами
  (PHPUnit: 49 тестов, юнит + интеграция на отдельной тестовой БД).

Команды: `app:prices:import`, `app:usage:import`, `app:billing:rate`,
`app:billing:report`, `app:billing:reprice`.
