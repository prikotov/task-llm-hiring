Учёт расходов LLM-токенов: импорты, тарификация, отчёт, перерасчёт

Каркас Symfony Console + PostgreSQL реализован полностью:

- app:prices:import — идемпотентная загрузка справочника
  (провайдеры, модели, строки цен) из JSON; upsert по естественным
  ключам, строки с неизменным содержимым не переписываются.
- app:usage:import — JSONL-загрузка событий; дубли по
  (provider, provider_request_id) игнорируются, первая доставка —
  каноническая; некорректная строка — ошибка всего файла (код 1).
- app:billing:rate — тарификация ещё не рассчитанных событий по
  последней действующей строке цен (valid_from <= ts, граница
  включительная); точная десятичная арифметика (bcmath, без float),
  округление ровно один раз — HALF_UP до 6 знаков; события без
  действия цен не падают — остаются unrated и повторно
  перепроверяются.
- app:billing:report — CSV на stdout: user,model,tokens_input,
  tokens_output,tokens_cache_read,tokens_cache_write,cost_usd;
  group by (user, provider/model), сортировка по возрастанию,
  TOTAL; unrated вне отчёта.
- app:billing:reprice (бонус) — ретро-коррекция строк цен и
  пересчёт затронутых событий с аудитом (reprice_corrections) и
  выводом REPRICED_EVENTS=… / REPRICE_DELTA_USD=…; повторное
  применение одной и той же коррекции идемпотентно, дублей
  начислений нет.

Схема — миграция (migrations/), ссылаемые таблицы, естественные
уникальные ключи и индексы в ORM-метаданных; bin/console,
make migrate, make test, юнит-тесты домена (34 теста) — работают.
