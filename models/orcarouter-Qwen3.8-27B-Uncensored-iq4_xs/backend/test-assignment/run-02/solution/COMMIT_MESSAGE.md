# COMMIT_MESSAGE.md

billing: консольный учёт расходов на LLM-токены (импорт, тарификация, CSV-отчёт, ретро-коррекция)

Реализовано всё задание TASK.md плюс бонус:

- Справочник цен (провайдеры с оф-пиковым окном, модели, строки цен с
  valid_from) — импорт JSON с валидацией и апсёртом по
  (provider, model, valid_from); деньги — только bcmath-строки.
- События использования — импорт JSONL, дедупликация по ключу
  (provider, provider_request_id), транзакция на весь файл, строка с
  ошибкой не принимает файл целиком.
- app:billing:rate — тарификация pending-событий строкой, действовавшей
  в момент события (valid_from включительно); единый тариф
  per_1m_tokens_unified; оф-пиковая скидка провайдера (окно UTC может
  переходить через полночь); округление ровно одно — стоимость события
  до 6 знаков HALF_UP. Бесценные события не блокируют запуск: их
  перечисление — в stderr, код возврата 0.
- app:billing:report — CSV в stdout: агрегация по (user, model) в
  периоде [from, to) + строка TOTAL; суммы — сумма округлённых
  стоимостей событий.
- Бонус: app:billing:reprice <file> — исправленная строка цен
  (тот же ключ) записывается поверх, события, рассчитанные именно по
  этой строке (у события хранится ссылка price_line_id), пересчитываются;
  вывод REPRICED_EVENTS и REPRICE_DELTA_USD.

Схема — миграция Doctrine (4 таблицы, уникальные ключи, FK). Тесты:
21 юнит-тест, включая фиксированные значения из примера расчёта
(14.262499 / 11.000000 / 8.400000 / TOTAL 33.662499).
