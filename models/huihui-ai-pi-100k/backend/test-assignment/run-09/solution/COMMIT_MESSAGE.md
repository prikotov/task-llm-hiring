billing: учёт расходов на LLM-токены по тарифам провайдеров

Реализован консольный контур (Symfony/Doctrine/PostgreSQL):
загрузка справочника цен (упsert по естественным ключам), приём журнала
событий с дедупликацией по (provider, provider_request_id), тарификация
по исторической строке цены с учётом схемы тарификации и оф-пикового
окна провайдера, CSV-отчёт по паре (user, модель), бонусная команда
app:billing:reprice для ретро-коррекции цен.

Деньги считаются только bcmath (шкалы 16–20): без промежуточного
округления, ровно одно округление HALF_UP до 6 знаков на
стоимость события, суммы отчёта — сумма уже округлённых стоимостей
(не float).

Точные десятичные вычисления покрыты юнит-тестами в tests/Domain
(Decimal, OffPeakPolicy: вкл. границы и полночь, Rater: обе схемы тарификации).
Приёмка по TASK.md пройдена, включая сценарии дедупа и reprice.
