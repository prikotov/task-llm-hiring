Учёт расходов на LLM-токены

Новое консольное приложение (PHP 8.4+/Symfony 8/PostgreSQL 17) для
разбора истории цен и событий использования, расчёта стоимости по
схемам per_1m_tokens и per_1m_tokens_unified, применения оф-пиковых
скидок и формирования CSV-отчёта по пользователям и моделям.

Ключевые решения:
- точная десятичная арифметика (bcmath, масштаб 20) для всех
  промежуточных вычислений; единственное округление — HALF_UP до
  6 знаков после точки на итоговую стоимость события;
- естественные ключи (composite PK) для всех таблиц;
- идемпотентный импорт цен (upsert) и событий использования
  (dedup по (provider, provider_request_id));
- оф-пиковые скидки по окну провайдера с multiplier;
- идемпотентная тарификация: повторный запуск не доначисляет;
- бонус: app:billing:reprice — ретро-коррекция цены с пересчётом
  уже рассчитанных событий.

Схема БД разворачивается через Doctrine Migrations на чистой базе.
