Биллинг LLM-провайдеров: импорт цен и журнала, точная тарификация и CSV-отчёт

Реализован полный контур: app:prices:import, app:usage:import,
app:billing:rate, app:billing:report и бонусная app:billing:reprice
для ретро-коррекции цен. Все суммы считаются в bcmath (без float)
с единственным округлением HALF_UP до 6 знаков; оф-пик окно
[старт, финиш) с переносом через полночь умножает итоговую стоимость
события; дедупликация событий по (provider, provider_request_id);
события без применимой ставки остаются unrated и подхватываются
повторным rate после появления цены. Отчёт группирует rated-события
по (user, model) за период [from, to) с итоговой строкой TOTAL.
Схема БД разворачивается миграцией doctrine/migrations на чистой базе.

Тесты: 23 (6 классов) — юнит на Decimal/OffPeak/Rater/парсеры
и функциональный прогон полного цикла на реальной PostgreSQL
(пример TASK.md воспроизводится байт-в-байт, идемпотентность,
окна оф-пика, unrated->rated, reprice).
