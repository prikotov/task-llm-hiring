Учёт расходов на LLM-токены: справочник цен, события, расчёт, отчёт, ретро-коррекция

Реализовано задание из TASK.md целиком, включая бонус:

- app:prices:import — идемпотентная загрузка провайдеров (в т.ч. off-peak),
  моделей и строк цен (per_1m_tokens / per_1m_tokens_unified) с upsert по
  (provider, model, valid_from);
- app:usage:import — загрузка событий из JSON Lines с дедупликацией по
  (provider_code, provider_request_id); события без цены в каталоге получают
  статус unrated и ждут расчёта;
- app:billing:rate — расчёт стоимости unrated-событий: ближайшая строка цены
  (valid_from <= ts), off-peak-окно с включаемым началом и невключаемым концом
  (допустимо через полночь), все деньги — bcmath/DECIMAL, одно округление
  roundHalfUp до 6 знаков в конце;
- app:billing:report — CSV по (user, модель) + строка TOTAL, время UTC,
  границы --from/--to в ISO-8601, вывод байт-в-байт соответствует примеру из
  TASK.md;
- app:billing:reprice (бонус) — ретро-коррекция: upsert исправленных строк цен
  по справочнику, пересчёт только затронутых рассчитанных событий, вывод
  REPRICED_EVENTS и REPRICE_DELTA_USD; повторный отчёт показывает пересчитанные
  суммы без задвоений;
- ошибки валидации и нечитаемых файлов — человекочитаемое сообщение в stderr и
  exit code 1.

Данные и время: NUMERIC для всех денег и ставок, TIMESTAMP(0) WITHOUT TIME ZONE
в UTC. Float в расчётах не используется.

Тесты: 70 (61 юнит + 9 интеграционных, в т.ч. полный приёмочный сценарий,
идемпотентность повторного импорта, дедупликация, границы off-peak через
полночь, unrated→rated, ретро-коррекция, коды ошибок).
