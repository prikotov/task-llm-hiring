# openai/gpt-6-luna (через OpenRouter)

## Характеристики

- Провайдер: OpenAI, доступ — OpenRouter (`openai/gpt-6-luna`), не на nserv
- Цена: $0.10/1M входных, $0.50/1M выходных; контекст 1.05M токенов
- Режим на собесе: reasoning effort **low** (аналог think-off у локальных)
- Локальный тег отсутствует — это облачная модель, папка ведётся по конвенции
  (слаг OpenRouter с `/` → `-`)
