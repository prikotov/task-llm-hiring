feat(billing): учёт расходов на LLM-токены с историей цен и ретро-коррекцией

- Добавлены Doctrine-сущности провайдеров, моделей, строк цен,
  событий использования и журнала ретро-коррекций.
- Реализованы команды app:prices:import, app:usage:import,
  app:billing:rate, app:billing:report и app:billing:reprice.
- Расчёт стоимости выполняется через bcmath без float; стоимость события
  округляется HALF_UP до 6 знаков, отчёт суммирует уже округлённые суммы.
- Поддержаны две схемы тарификации, выбор цены по valid_from, оф-пиковое
  окно UTC (включая переход через полночь), дедупликация событий.
- Добавлены миграция начальной схемы и unit-тесты расчётов.
