# deepseek-flash (DeepSeek V4.1 Flash, родной API)

## Характеристики
- Провайдер: DeepSeek (облачная), родной API api.deepseek.com (OpenAI-совместимый),
  модель `deepseek-flash`; ключ из env-файла MODELS_RU_ENV
- **Версии снапшотов по этапам** (алиас всегда указывает на актуальный):
  интервью этапа 1 (2026-10-09) — базовый DeepSeek-V4.1-Flash;
  тестовое задание этапа 2 (2026-10-18) — DeepSeek-V4.1-Flash-1017
  (обновление 2026-10-17, changelog api-docs.deepseek.com/updates).
  При сопоставлении этапов это фактически две разные версии модели.
- reasoning_effort переключает размышления: минимум low, максимум high
  (в отчётах pi-уровни: low/minimal → low, max → high)
- Тариф: $0.30/1M вход, $0.006/1M кэш-хит, $1.20/1M выход (пик; оф-пик ×0.5)

## Карта знаний PHP (knowledge-map, 2026-11-08) — калибровка потолка

Серия deep v4 через родное API DeepSeek (V4.1-Flash, `--api deepseek`,
reasoning_effort low — стандарт облачных серий, Comparable с
think-off локальных; 5 прогонов run-01…05 × 296 клеток = 240 база+версии + 56
глубина). **Калибровочный якорь сверху** (рекомендация trust-mimo п.5):
- База L1–L8: **97.9%** — шкала не сатураирует и на сильной облаке
  (huihui medium 92.2 → deepseek 97.9, разница живая).
- Глубина: **94.3%** (L9 100.0 / L10 88.6) — береговая линия L10 держит
  даже сильную модель: T12-L10 (бит E_STRICT) и T18-L10 (счёт
  «выполнено + failure» = 2,1) — **0/5**, T11-L10 и T20-L10 — 50%.
  Промахи содержательные: deepseek уверенно отвечает по устаревшей
  семантике («E_STRICT входит в E_ALL», «не-static провайдер =
  error-тест PHPUnit») против машинной правды — ровно то, что зона
  должна ловить.
- Полная шкала глубины: deepseek 94.3 → huihui medium 87.1–90.0 →
  huihui off/low 70.4–88.6 → medgemma 59.6–62.9 → gemma4:e2b 35.0–36.8.
- Дисциплина: JSON 99.8%, флипов в deep 3/56 (очень стабильна).
- Стоимость серии: 3646 c, 0.25M вх / 0.30M вых ток → ~$0.43 по пиковому
  тарифу ($0.30/1M вх, $1.20/1M вых; кэш 0 — серверный prefix-cache не
  задействован, клетки независимы).
Детали: run-01…05 (session.json, report.html),
compare-low-ru-v8.html, reports/knowledge-map-series.html (25 карт).
