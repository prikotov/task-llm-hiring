# deepseek-flash (DeepSeek V4.1 Flash, родной API)

## Характеристики
- Провайдер: DeepSeek (облачная), родной API api.deepseek.com (OpenAI-совместимый),
  модель `deepseek-flash`; ключ из env-файла MODELS_RU_ENV
- **Версии снапшотов по этапам** (алиас всегда указывает на актуальный):
  интервью этапа 1 (2026-10-09) — базовый DeepSeek-V4.1-Flash;
  тестовое задание этапа 2 (2026-10-18) — DeepSeek-V4.1-Flash-1017
  (обновление 2026-10-17, changelog api-docs.deepseek.com/updates).
  При сопоставлении этапов это фактически две разные версии модели.
- reasoning_effort переключает размышления: минимум low, максимум high
  (в отчётах pi-уровни: low/minimal → low, max → high)
- Тариф: $0.30/1M вход, $0.006/1M кэш-хит, $1.20/1M выход (пик; оф-пик ×0.5)
