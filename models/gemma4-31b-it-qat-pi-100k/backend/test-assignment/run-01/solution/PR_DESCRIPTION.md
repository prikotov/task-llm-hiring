## Описание изменений

Реализована система учёта расходов на LLM-токены в соответствии с требованиями TASK.md.

### Ключевые решения и допущения:
1. **Предметное моделирование**:
   - `Provider`: хранит общие данные провайдера и настройки оф-пик окна.
   - `Model`: связывает провайдера и код модели.
   - `Price`: хранит историю цен для модели с привязкой к `valid_from`.
   - `UsageEvent`: хранит данные о событии использования, ссылку на примененный `Price` (для оптимизации репрайсинга) и итоговую стоимость.
2. **Расчёты**:
   - Использовано расширение `bcmath` для всех финансовых вычислений.
   - Промежуточный масштаб (scale) установлен в 16 знаков.
   - Округление итоговой стоимости события реализовано по правилу HALF_UP до 6 знаков.
3. **Идемпотентность**:
    - Импорт цен: upsert по `(provider, model, valid_from)`.
    - Импорт событий: игнорирование дублей по `(provider, provider_request_id)`.
4. **Оф-пик**:
    - Время проверяется в формате "HH:mm" UTC. Обработан случай перехода окна через полночь.
5. **Репрайсинг (Бонус)**:
    - Реализован поиск всех событий, которые были тарифицированы с помощью изменённой строки цен, и их пересчёт с вычислением дельты.

### Как проверял:
1. Поднял базу: `make db-up`.
2. Развернул схему: `bin/console doctrine:migrations:migrate`.
3. Загрузил данные из fixtures:
   `bin/console app:prices:import fixtures/prices.json`
   `bin/console app:usage:import fixtures/usage.jsonl`
4. Запустил тарификацию: `bin/console app:billing:rate`.
5. Сформировал отчёт за сентябрь:
   `bin/console app:billing:report --from=2026-09-01T00:00:00Z --to=2026-10-01T00:00:00Z`
   Результат совпадает с примером байт-в-байт.
6. Проверил повторный импорт и тарификацию — результат не изменился.

### Отступления от каркаса:
- Добавил поле `price_id` в таблицу `usage_events` для обеспечения эффективности команды репрайсинга (чтобы не пересчитывать все события мира при изменении одной строки цены).
- Изменил имя колонки `user` на `username` в БД, так как `USER` является зарезервированным словом в PostgreSQL.
