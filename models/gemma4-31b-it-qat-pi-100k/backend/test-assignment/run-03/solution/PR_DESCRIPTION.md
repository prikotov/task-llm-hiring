# Описание PR: Система учёта расходов на LLM-токены

## Что сделано
Реализован функционал учёта и тарификации использования LLM-токенов в соответствии с требованиями TASK.md.

### Ключевые решения и архитектура:
1. **Доменная модель**:
   - Созданы сущности `Provider`, `Model`, `Price` и `UsageEvent`.
   - Для обеспечения гибкости и упрощения связей использованы суррогатные ID в `Model` и `Price`.
   - `UsageEvent` хранит `modelCode` и `providerCode` для возможности импорта событий до создания справок по моделям.
2. **Тарификация**:
   - Реализован `BillingService` для расчёта стоимости одного события.
   - Использовано расширение `bcmath` для всех денежных вычислений с точностью 16 знаков до окончательного округления.
   - Округление итоговой стоимости события выполнено по правилу `HALF_UP` до 6 знаков после запятой.
   - Обработана логика оф-пик скидок, включая окна, переходящие через полночь UTC.
3. **Импорт и дедупликация**:
   - `PriceImporter` выполняет идемпотентный upsert справочников.
   - `UsageImporter` обеспечивает дедупликацию событий по ключу `(provider, provider_request_id)`.
4. **Отчётность**:
   - `ReportService` группирует данные по пользователю и модели, суммирует токены и округлённые стоимости.
5. **Ретро-коррекция (Бонус)**:
   - Реализована команда `app:billing:reprice`, которая обновляет цены и пересчитывает стоимость только тех событий, которые были тарифицированы по изменённому прайсу.

### Допущения:
- Имя столбца `user` в PostgreSQL заменено на `userName`, так как `user` является зарезервированным словом.
- Предполагается, что `Price` всегда привязаны к существующим `Provider` и `Model`.

### Как проверяли:
1. Развёртывание схемы БД с нуля (`bin/console doctrine:schema:update --force`).
2. Импорт тестовых данных из `fixtures/prices.json` и `fixtures/usage.jsonl`.
3. Запуск тарификации `app:billing:rate`.
4. Сравнение вывода `app:billing:report` с эталонным (совпадение байт-в-байт).
5. Проверка идемпотентности повторным импортом.
6. Тестирование ретро-коррекции с помощью файла исправлений.

### Отступления от каркаса:
