feat(billing): учёт расходов на LLM-токены

Реализовано консольное приложение для расчёта расходов на токены:

- app:prices:import — идемпотентный upsert провайдеров (по code),
  моделей (по provider+code) и строк цен (по provider+model+valid_from);
- app:usage:import — приём JSONL-событий с дедупликацией по
  (provider, provider_request_id);
- app:billing:rate — тарификация нерассчитанных событий ценой,
  действовавшей в момент события; unrated-события повторяются при
  каждом запуске;
- app:billing:report — CSV-отчёт по (user, model) с TOTAL;
- app:billing:reprice — ретро-коррекция цен с журналом корректировок
  и пересчётом затронутых событий.

Ключевые решения:

- деньги — только Decimal поверх bcmath (float исключён), округление
  единственное: стоимость события до 6 знаков HALF_UP;
- поддержаны обе схемы тарификации (per_1k по видам и unified)
  и оф-пиковое окно с переходом через полночь;
- время всегда UTC, хранится с точностью до секунды;
- слои: Domain (чистая логика и расчёты), Application (сценарии),
  Infrastructure (Doctrine, чтение файлов), UI\Console (команды);
- миграция схемы БД + 31 unit-тест на деньги, окно, расчёт и парсинг.
