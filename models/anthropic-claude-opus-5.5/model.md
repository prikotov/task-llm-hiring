### Инфраструктурные находки прогона

- **Anthropic не кэширует промпты без явных `cache_control`** (в отличие от
  OpenAI, где кэш автоматический): A/B-тест на Haiku показал −70% стоимости
  с метками при идентичном объёме. Флаг `--cache` в runner_openrouter.py.
- **Кап 64 КБ на тело запроса /v1/systemone у ollama**: ответы Opus по
  16–20k символов + экранированная кириллица (`\uXXXX`, ×3 раздутие)
  переливались через лимит → HTTP 413. Исправлено: `ensure_ascii=False`
  во всех judge-скриптах (UTF-8 напрямую, кириллица 2 байта/символ).

выхода против 36–42k у OpenAI-моделей. Для нашего формата собеса

### Прогон через OrcaRouter (2026-10-22, run-03, effort low) — прерван лимитом ключа

OrcaRouter (orcarouter.ai) подключён как запасной провайдер после того, как
пополнить OpenRouter не удалось (нативный anthropic-messages, /v1/messages,
Bearer, без прокси; claude-haiku-5.5 в каталоге нет, opus-5.5 есть). Дым на
простом запросе прошёл чисто (8 с, task выполнен). Полный прогон low работал
29.4 мин (51 вызов, ~$4.38: вход 100 ток., кэш-чтение 4.41M, кэш-запись 157K,
выход 126.9K — из них reasoning 70.8K) и оборвался на 403 err_key_quota:
«$0.78 left on the key, this request needs $0.80». Дерево решения осталось в
полу-состоянии (2909 строк диффа, 57 файлов, 0/11 — PHP падает при загрузке
консоли). Прогон НЕ ПРОЙДЕН ни по чекеру, ни по судьям — судейские ярусы
на нём не запускались; засчитана только проверка сантехники провайдера. Дороже открытого прогона low ($1.24): выход ×2.5 и 29 мин против
7.3 — разброс temp=1, не дефект харнеса (все 51 вызов до лимита прошли норм).
Вывод: прогону opus нужен запас лимита ~$6-8 на ключе.

**Диагноз перерасхода (2026-10-22):** в записи модели стояли compat-флаги
`forceAdaptiveThinking` + `supportsMidConvoEffort` (скопированы из каталога pi
для openrouter) — оба включают adaptive-мышление Anthropic, где effort — лишь
намёк без потолка. Отсюда 70.8K reasoning за «low»-прогон ($4.38). Исправлено:
флаги убраны, pi работает в классическом бюджетном режиме (DEFAULT_THINKING_
BUDGETS: low 2048 / medium 8192 / high и max 16384 reasoning-токенов на вызов),
что по экономике совпадает с открыскими прогонами (run-01 low: 15K reasoning
итого, $1.24). Смоук бюджетного режима чистый (reasoning 19–26 на вызов).
