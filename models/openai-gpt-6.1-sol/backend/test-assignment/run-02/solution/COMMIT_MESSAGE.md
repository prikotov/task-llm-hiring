Реализовать консольный учёт расходов на LLM-токены

- Добавить доменную модель провайдеров, моделей, истории цен и использования.
- Реализовать атомарный импорт цен и дедупликацию событий по ключу провайдера.
- Рассчитывать расходы точной арифметикой BCMath с учётом времени и оф-пика.
- Формировать CSV-отчёт по уже округлённым стоимостям событий.
- Добавить ретро-коррекцию цен с журналом изменений стоимости.
- Развернуть схему миграцией Doctrine и покрыть сценарии модульными и
  интеграционными тестами PostgreSQL, включая конкурентные запуски.
