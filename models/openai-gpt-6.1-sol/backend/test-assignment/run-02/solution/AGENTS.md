# AGENTS.md — короткая памятка для AI-агента в этом репозитории

Задание — в `TASK.md`.

1. Новый код — в `src/` (PSR-4 `App\`, автозагрузка настроена), тесты —
   в `tests/`. Зависимости уже в `vendor/`.
2. Перед завершением проверь сам: `bin/console` работает, на чистой базе
   разворачивается схема БД, приёмка из TASK.md выполняется.
3. По завершении создай в корне `COMMIT_MESSAGE.md` и
   `PR_DESCRIPTION.md` (формат — в конце TASK.md). Все отступления от
   каркаса — изменённые файлы, добавленные зависимости, альтернативные
   решения — перечисли в `PR_DESCRIPTION.md` с обоснованием.

Пиши тексты (сообщения, описания, заметки) на русском языке.
