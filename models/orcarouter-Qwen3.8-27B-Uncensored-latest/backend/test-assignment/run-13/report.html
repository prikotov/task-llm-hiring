Связанность классов: Ce, Ca, нестабильность I

Обоснование

ревьюер яруса 3
Обязательная часть не проходит приёмку: импорт usage отбрасывает события с нулевыми токенами («$errors[] = "$label: all-zero token counts"»), хотя задание явно разрешает «любые могут быть нулевыми (в т.ч. все)» — из-за этого сыплются usage_import, import_duplicates и rate_counts (16/1 вместо 17/1). Формат unrated-строки неверен: ts печатается как «2026-07-31T23:00:00+00:00» вместо ISO-UTC «Z» (формат ATOM в rate()).
