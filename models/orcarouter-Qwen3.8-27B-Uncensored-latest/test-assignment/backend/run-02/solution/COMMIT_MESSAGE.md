feat: учёт расходов на LLM-токены — справочник цен, импорт событий, тарификация и CSV-отчёт

Реализовано консольное приложение (bin/console) по ТЗ:

- app:prices:import — идемпотентный upsert провайдеров, моделей и строк
  цен (валидация формата, строки-десятичные для денег);
- app:usage:import — JSONL-импорт событий с дедупликацией по
  (provider, provider_request_id) через ON CONFLICT DO NOTHING;
- app:billing:rate — выбор исторической строки цен
  (max valid_from <= ts), две схемы тарификации, оф-пиковая скидка
  провайдера, единственное округление события до 6 знаков HALF_UP;
  unrated-события повторяются на каждом запуске;
- app:billing:report — CSV по (user, <provider>/<model>) за период
  [from, to), строка TOTAL; точное десятичное суммирование;
- бонус app:billing:reprice — ретро-коррекция: upsert исправленных
  строк цен, пересчёт только событий, тарифицированных заменённой
  строкой, журнал в reprice_corrections, вывод REPRICED_EVENTS/
  REPRICE_DELTA_USD.

Деньги — только точная десятичная арифметика (обёртка Decimal на bcmath,
масштаб 20, float для денег не используется). Схема БД — Doctrine
migration, разворачивается на чистой базе (make migrate).

Тесты: DecimalTest, RatesCalculatorTest
(23 ассерта): округление HALF_UP, обе схемы тарификации, оф-пик, нулевые токены.

Проверено: приёточные сценарии ТЗ (импорт + rate + report совпадает
 байт-в-байт, идемпотентность повторного импорта, коды выхода 0/1,
повторная тарификация unrated, reprice с дельтой).
