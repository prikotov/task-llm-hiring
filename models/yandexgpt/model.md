# YandexGPT Pro 5 (Яндекс, через API TasK)

## Характеристики

- Провайдер: Яндекс (AI Studio), URI `gpt://b1gvln02oo3us3oomdfg/yandexgpt/latest`;
  по детализации биллинга алиас резолвится в **YandexGPT Pro 5 (SyncAPI)** —
  API эхом возвращает сам URI, точное имя видно только в чеке
- Доступ: ключ из `~/MyProjects/TasK/Development/.env.dev.local` (в workspace
  не копируется), раннер `interview/runner_ru_cloud.py --provider yandexfm`
- Тариф (детализация биллинга 2026-10-09): **плоский ₽1.20/1k токенов любого
  типа** — вход, кэш, выход (71.62k кэш → ₽85.94, 16.41k вх → ₽19.70,
  9.58k вых → ₽11.49 — везде ровно 1.2). Кэш не удешевляет токены
  (у OpenAI/Anthropic −70%), даёт только скорость

## Вывод

Для PHP-разработки YandexGPT Pro 5 в текущем виде непригоден: шестая часть
технических вопросов отсекается контент-фильтром, знание стека — на уровне
слабейших локальных моделей. Плюсы: честность (не галлюцинирует — отказывается)
и скорость. Цена полного собеса ≈₽400 ($4.70) — дороже Sol при наихудшем
качестве: плоский тариф без кэш-скидки делает длинные контекстные собесы
на Яндексе дороже, чем у западных облаков с −70% на кэш.

Примечание: прогон прерывался по 403 (исчерпание баланса) и продолжен через
`--resume` с Q18 с полным восстановлением контекста (`resumed_at` в session.json).
