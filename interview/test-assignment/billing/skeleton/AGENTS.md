# AGENTS.md — правила для AI-агента в этом репозитории

Задание — в `TASK.md`. Это короткие правила работы в репозитории; они
обязательны, как и требования задания.

1. **Окружение офлайн.** Сети нет и она не нужна: зависимости уже в `vendor/`.
   Не запускай `composer` (require/update/install), `git clone`, `curl` и
   любые другие сетевые команды.
2. **Схема БД — только миграциями.** Любое изменение схемы — через
   Doctrine-миграции (`doctrine:migrations`), не через `doctrine:schema:update`
   и не вручную через SQL в обход миграций.
3. **Не изменяй** файлы: `TASK.md`, `AGENTS.md`, `README.md`, `fixtures/`,
   `composer.json`, `composer.lock`, `docker-compose.yml`, `Makefile`,
   `phpunit.xml.dist`. Если для решения объективно нужно что-то из этого
   изменить — не меняй, а зафиксируй потребность как допущение в
   `PR_DESCRIPTION.md`.
4. **Новый код** клади в `src/` (PSR-4 `App\`, автозагрузка настроена),
   тесты — в `tests/`.
5. **Перед завершением** проверь сам: `bin/console` работает; на пустой БД
   `make db-up && make migrate` проходит без ошибок; приёмка из TASK.md
   (раздел «Приёмка») выполняется.
6. **По завершении** создай в корне `COMMIT_MESSAGE.md` и
   `PR_DESCRIPTION.md` (требования — в конце TASK.md).

Пиши тексты (README-заметки, сообщения, описания) на русском языке.
