# Q01 — Возможности PHP 8+ для чистого кода

## Чек-лист сильного ответа
- [ ] Enum (backed enum'ы) — вместо строк-констант и case-проверок, доменные статусы
- [ ] readonly свойства / readonly-классы — неизменяемость на уровне языка
- [ ] Constructor property promotion — компактные DTO/VO
- [ ] match-выражение — исчерпывающее ветвление без break, строгие сравнения
- [ ] Атрибуты (`#[...]`) — декларативные метаданные вместо аннотаций-комментариев
- [ ] Типизация: union / intersection / DNF types, nullable, mixed осознанно
  (пометка судье: nullable — фича 7.1, а не 8.x; упоминание его как «нового в 8» =
  красный флаг «приписывание версии»)
- [ ] Nullsafe operator `?->`
- [ ] Named arguments / first-class callable syntax (желательно)
- [ ] Привязка фич к смыслу: НЕ «список ради списка», а «что это даёт доменному коду»
- [ ] Код-примеры корректны и запускаемы по виду (синтаксис реальный)
- Бонус (свежее, не обязательно): 8.3 — `#[\Override]`, `json_validate()`,
  типизированные константы; 8.4 — property hooks, asymmetric visibility.

## Красные флаги
- Выдуманные возможности («generics в PHP 8», «множественное наследование»)
- Приписывание версии: arrow functions как «PHP 8» (это 7.4)
- Примеры с синтаксическими ошибками или неработающим кодом
- Список фич без объяснения «зачем» — механическое перечисление

## Образец сильного ответа
«Для доменного кода я бы выделил: backed enum для статусов задачи — тип
гарантирует валидное состояние; readonly-классы для Value Object —
неизменяемость проверяет сам язык, а не дисциплина разработчика; promotion
делает VO из трёх строк; match — исчерпывающая обработка случаев, которую
статический анализ проверяет на полноту; атрибуты — маппинг и метаданные без
грязных комментариев. Пример: ... (код VO на promotion+readonly с enum-полем)».

## Шкала 0–4
- 0 — не знает фич 8.x либо код нерабочий
- 1 — называет 1–2 фичи, примеры не показывает или ломаные
- 2 — верный список 3–5 фич, примеры в целом корректные, без привязки к смыслу
- 3 — список + корректные примеры + объяснение, что фича даёт доменному коду
- 4 — как «3» + свежие версии (8.3/8.4), вкус и приоритизация («важнейшее — ...»)
