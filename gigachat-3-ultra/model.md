# GigaChat-3-Ultra (Сбер, через API TasK)

## Характеристики

- Провайдер: Сбер, endpoint `https://api.giga.chat/v1/chat/completions`
  (единый URL для физлиц и юрлиц с 16.07.2026; старый
  `gigachat.devices.sberbank.ru` остаётся для GigaChat-2)
- Модель: `GigaChat-3-Ultra` — **доступна только физическим лицам и только
  во Freemium** (юрлицам не продаётся, платного пакета нет)
- Ключ — OAuth Basic из `<env-файл с ключами>`
  (scope GIGACHAT_API_PERS), раннер `interview/runner_ru_cloud.py
  --provider gigachat --model GigaChat-3-Ultra`
- Freemium-квота Ultra: **50 млн токенов на 12 мес**

## Backend

### run-01 (2026-10-09)

- 35 вопросов + 6 углублений, 41 запрос, 11.0 мин
- Токены: 558 278 некэшированных вх + 721 216 precached + 58 865 вых
  = **1 338 359 → 2.7% freemium-квоты, ₽0**
- **clef: 3.32** — прыжок на +0.72 над GigaChat-2 Max (2.60); уровень лучших
  локальных 27B (qwen3.8 3.26, ornith-35b с мышлением 3.40) и дешёвых
  облаков (Luna), при этом сильно ниже Sol/Opus
- p-галлюцинаций: 0.226 (между облаком 0.12–0.18 и локальными 0.27–0.38),
  need_review 0.28
- **Провокации: 3/3** — лучший результат среди всех протестированных:
  - Q24: `FORCE INDEX` в PostgreSQL нет — вскрыто сразу, с объяснением
    архитектурного различия;
  - Q25: выдуманный процент замедления strict_types не подтверждён
    («менее 1%, погрешность»), механизм верный — и фактически описана
    инверсия: дополнительная работа приведений возникает в слабом режиме;
  - Q26: «Doctrine не поддерживает составные ключи» — предпосылка
    **опровергнута прямо** («поддерживает, но с оговорками Unit of Work») —
    там, где GigaChat-2 Max её проглотил с конфабуляцией
- Ответы развёрнутые структурированные (1–2k токенов), без отказов и пустых

## Вывод

Лучшая из российских моделей в тесте — единственная, кто чисто прошёл все
три провокации. Для PHP-разрыва с западными облаками всё ещё нет (Sol/Opus
выше на 0.2–0.5 балла), но разрыв с GigaChat-2 Max закрыт почти полностью.

## Если использовать в работе (юрлицо)

Сбер юрлицам GigaChat-3-Ultra не продаёт (в тарифах юрлиц только
GigaChat-2 Lite/Pro/Max); коммерческий доступ к линейке Ultra — только
через **cloud.ru Foundation Models** (туда же с 01.09.2026 направляют всех
новых клиентов Сбера): GigaChat 3.5 Ultra — **₽96/1M вход + ₽289/1M выход**
(≈$1.16/$3.47). Наша сессия в таких ценах: **₽71 (~$0.83)** без учёта кэша,
**₽140 (~$1.65)** если кэш тарифицируется как входные токены. Ирония:
флагман через cloud.ru выходит дешевле GigaChat-2 Max по сберовскому
тарифу (₽650/1M без разбивки) — у cloud.ru раздельный прайс с дешёвым
входом, а собес входо-ёмкий (92% входных токенов).
