# Эталон-карточки решений (этап 3, код-ревью)

Четыре решения этапа 2, отобранных как объекты ревью. Карточка замораживает
эталон ревьюера: ожидаемые оси A/B (вердикт яруса 3 — судья, видевший
чекер), ожидаемое функциональное соответствие заданию и список известных
дефектов (из вердиктов ярусов 3/4 и упавших сценариев чекера; ключевые
дефекты верифицированы чтением кода).

- `good` — huihui-ai-pi-100k run-02: полный зачёт (13/13), образцовый процесс.
- `mid` — muse-glimmer run-03: всё обязательное работает (11/11), архитектурно слабое, тестов нет.
- `tricky` — qwen3.8-27b-pi-100k run-03: стоимости отчётов не сходятся с golden (тарифное правило); слепой судья яруса 4 дал 4.0 — слепое пятно.
- `bad` — gemma4-31b-it-qat-pi-100k run-02: стоимости не сходятся, пустые миграции, дубли-риск в импорте, артефактов нет.

**Заморожены 2026-10-30.** После старта ревью-прогонов карточки не меняются:
сравнение ревьюеров с эталоном теряет смысл при плавающем эталоне. Правки —
только до пилота и отдельным коммитом с обоснованием.
